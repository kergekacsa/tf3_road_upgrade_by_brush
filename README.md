# Road & Rail Upgrade Brush

A Transport Fever 3 mod (`kacsa_road_upgrade_brush`). It puts one tool in the build menu, in two places: **Road Upgrade Brush** under **Roads**, in the **Tools** tab, as the green brush, and **Rail Upgrade Brush** in the rail tools. It is the same tool; the entry decides the mode it opens in (Roads or Rails), and a switch at the top of the toolbar changes the mode. It selects roads (or rail tracks) with a brush and upgrades them to a street type (or track type) in one press. The mod is independent: it needs no other mod and is built to run next to the original mods "Road Upgrade All in One" and "Bulk Bulldozer". It has no single-click tool, so the original one does not appear twice in the menu.

## Before you start

- No other mod is needed. The original "Road Upgrade All in One" (`road_upgrade_suite`) and "Bulk Bulldozer" MAY stay on. This mod uses its own file paths, text keys (`rub_*`), menu parameter keys, and Teal type names (`Rub*`), so it replaces no file of the originals.
- Three things are shared by design. (1) The toolbar status style: when Bulk Bulldozer or Smart Lanes is active, this mod uses their style rules and adds none of its own; the status text then looks as their style makes it. (2) The developer master switch mod `square_sqperf_all`, if installed, turns on the debug log of this mod. (3) The menu category `roads_tools` with order 5, the same order as the tool of Bulk Bulldozer; with both on, the menu lists both tools.
- Pause is handled by the mod: it pauses the game while it upgrades and sets the old speed back when it is done.

## How the brush tool works

1. Everything sits in the one toolbar on the left, from top to bottom: the radius, the Underground button, the road options, the progress, and the **Upgrade** and **Clear** buttons. Pick the road type, and optionally alley trees and noise barriers. Besides the slider, the keys **M** (larger) and **N** (smaller) change the radius step by step, and a held key repeats. They are the rotation keys of the game's construction tools, so rebinding them in the game settings rebinds them here.
2. Hold the left mouse button and paint over the roads. Every road that the brush circle touches is selected. Roads under the circle that are not selected yet show as a light pink preview, also while a selection waits. Selected roads are red. A road that already has the road type and the options set in the toolbar shows blue instead (light blue in the preview), and Upgrade leaves it alone.
3. Hold Shift while painting to remove roads from the selection. Every selected road the brush touches leaves the selection.
4. Press **Upgrade**, or press **Enter** while a selection waits. The mod sends one command per road. A road leaves the selection as soon as it is done, or when it already had the target type, so the highlight shrinks while the status line shows the progress (for example "Upgrading 12 of 50" with a bar). Roads that fail count for the progress too, and the retry rounds show as "Retrying failed ones". While it runs, the **Clear** button reads **Cancel**, and a third line says that it stops the progress. At the end the status line shows "X updated, Y failed" with the cost: green when something was updated (with "Y failed" in yellow when some roads failed), red when nothing was updated and some roads failed. It stays until your next stroke, upgrade or clear.
5. A **middle click** on a road (a click without dragging; a drag still turns the camera) copies its settings to the toolbar: road type, alley trees or noise barriers, bus lane, tram track, catenary, and the lock (a locked road sets Lock, an unlocked road sets Keep). Nothing is selected by this click. The status line shows a note when a one-way road, a road of a type the tool does not offer, or no road is under the cursor. When the lanes of the road match no combination of bus lane and tram track, those options are set off and the status line says so.
6. **Rails mode.** Switch **Roads | Rails** at the top of the toolbar, or open the tool from the rail tools. The toolbar then shows the **track type** (simple, standard, high speed) the **catenary** choice, and the **noise barrier** choice: **Keep** (default) leaves the catenary (or the barrier) of each track as it is, **Add** puts it on, **Remove** takes it off. The barrier is the one of the game for tracks (wooden until 1939, concrete from 1940), on both sides of the track (Add completes a side that lacks one); it is disabled while the Underground button is on, and a tunnel gets none. Painting, Shift, Enter, Upgrade, Clear, Cancel, the blue marking, the Underground button, and the middle-click copy work as for roads. Tracks that already have the target template and the target barrier state show blue. A change of the noise barrier replaces the track by the same template, so the game charges the full track cost for it, also for Remove. A quiet track of the mod Station Noise Barriers counts as its original track type (also for the middle-click copy), while the brush does not select it, because it is part of a station. A track with any other template is not selected and not changed. Switching the mode empties the selection. A middle click on a road in Rails mode (or on a track in Roads mode) only shows a note.
7. **Clear** or a right click empties the selection. While an upgrade runs, the button reads **Cancel**: it stops the upgrade after the road in progress, keeps the roads that are not done selected, and the tool stays open. After a click on the **Upgrade** button the game usually gives Esc to its own menu, which closes the tool instead; the upgrade then stops after the road in progress. Use **Cancel** to keep the tool open. Roads already upgraded stay upgraded.

## Limits

- Up to 200 roads per press. When 200 roads are selected, the status line reads "200 selected (max)" in yellow. A run takes about half a second per road, and the game stays paused while it runs.
- The brush offers the six two-way road types. The two one-way road types of Road Upgrade All in One are not offered.
- The Rails mode offers the three track types of the game (simple, standard, high speed) with or without catenary. The toolbar lists only the track types that the game offers in the current year (each time the toolbar updates; with only one type offered, there is no list). The catenary choice shows only for a track type that has a catenary version in the current year; for a type without one, an upgrade gives the tracks no catenary. Tracks of other mods are not offered, except the quiet tracks of Station Noise Barriers, which are parts of stations and are not selected. The Rails mode does not change tracks that belong to a construction, such as stations. Signals on a track were kept by the upgrade in the tests so far; the log marks `OBJECTS LOST` if an upgrade ever drops them. The Rails mode does not demolish anything: "Remove buildings in the way" does not apply to it.
- Alley trees do not exist for country roads. The toolbar shows a red note for impossible combinations.
- The brush skips roads of other players, parts of constructions, and industry roads. It upgrades town roads and roads without an owner.
- A road that already has the target type (and the same trees or barriers) is left alone and not charged.
- A road whose command fails is tried again twice, each time after all other roads. Roads that still fail stay selected, so another press tries them again.
- "Remove buildings in the way" is on by default. A town road with building lots can fail with "Unexpected parcel on a segment". The brush cannot upgrade such a road and does not demolish any house for it. It stays selected and counts as failed. Road Upgrade All in One (menu entry "Combined Road Upgrade") can upgrade many such roads, because its tool moves or removes the houses itself.
- A road that a placed asset (an asset group such as a decoration, a tree group, or a rock) blocks fails with "Collision". With "Remove buildings in the way" on, the first retry removes the asset, and the last retry sends the build with the game's errors ignored, as the Build Anyway mod does.
- The brush sends commands only while the game is paused. If it cannot read the game speed or cannot pause the game, it sends nothing and the roads stay selected with the note "Pause the game first".
- If the game gives no answer for 120 seconds, the tool gives up, sets the game speed back, and shows "No answer from the game". Only one upgrade runs at a time: a press while the previous upgrade still runs sends nothing and shows "previous upgrade still running".
- The cost is known only after the upgrade. There is no cost preview.
- There is no undo.
- The tool remembers the radius, road type, trees, barrier, bus lane, tram track, lock, and "Remove buildings in the way" during one game session. A new session starts with the defaults.
- Bus lane, tram track, catenary, and lock are offered as in Road Upgrade All in One (bus lane: no cars on the outer driving lanes; tram track and catenary: tram lanes on the outer driving lanes; lock: towns do not change the road). The lock has three states: Keep leaves the lock of each road as it is, Lock sets it, Unlock removes it.
- The brush gives a road the lanes of the street type you choose. With Tram track or Bus lane off, an upgrade removes a tram track or a bus lane that the road has.- The Underground button in the toolbar (or the shortcut G) switches the underground view on. While it is on, the brush selects tunnels only. While it is off, it selects roads on the ground only.
- The brush never selects a stand-alone tram track in Roads mode. A road with tram tracks on top of its lanes is selected.
- While the Underground button is on, alley trees and noise barriers are disabled and ignored: a tunnel has neither.
- The data layers of the layers menu work with the brush open. While a data layer is on, the underground view is not drawn, as with the base tools. The Underground button still selects tunnels only.

## Credits

- The road types, add-ons, and rules are taken from "Road Upgrade All in One" by kurowasiichi (mod.io 6487083). The headers of the copied files name the author. 24 of the road type, option, and problem texts in `strings.json` (the English and Traditional Chinese texts) are copies of the texts of that mod, with the keys renamed to `rub_*`. The road type tooltip is rewritten for the brush, and six short status texts (`rub_chip_*`) are new. The texts of the Rails mode are new too; their words for tracks, Mode, Add, Remove, Roads, and Catenary are the game's own. The road type names in the other languages are the names the game gives to its street templates. The tool icon and the mod.io image are drawn for this mod.
- The brush, selection, highlight, and toolbar code is taken from "Bulk Bulldozer" by square17 (mod.io 6434884). The headers of the copied files name the authors. In `strings.json`, 38 texts (for example "Selection" and "%d selected") in the 12 languages besides English are the translations of that mod, and a few more in some of the languages.

## Translations

The mod has texts in all 13 languages of the game: English, German, Spanish, French, Italian, Japanese, Korean, Dutch, Polish, Brazilian Portuguese, Russian, Simplified Chinese, and Traditional Chinese. Where the game has a translation of the same word (for example Clear, Cancel, Yes, No, Catenary, On, and Off), the mod uses the game's word. The road type names are the names the game gives to its street templates. The texts that come from Bulk Bulldozer and Road Upgrade All in One are listed under Credits. The other translations are machine-made and have not been checked by native speakers. Wrong or odd texts MAY be reported.

## Log

The mod writes to the game log (`crash_dump\stdout.txt`). Lines start with `[BrushUpgrade]`. The log shows each command, the game's messages, and the game speed. A circle that stops following the pointer writes a `stuck ring:` line on the next click, and the world layer writes `layer event` lines when it mounts or unmounts. The diagnostic lines (tool instances, world layer, cursor, segment to send) are off. To turn them on, set `probe.ENABLED = true` in `kacsa_road_upgrade_brush/content/road_upgrade_brush/proposal_probe.tl`.

## Release files

The mod folder is `kacsa_road_upgrade_brush/`. This README, `CONTEXT.md` (the terms), `ARCHITECTURE.md` (the code layout and the game facts), `docs/adr/` (the design decisions), `DEVELOPMENT-TOOLS.md` (the Teal and Lua checks), and `PUBLISHING.md` (the requirements for a mod.io upload or update) sit next to it, outside the folder that is uploaded.

- `mod.json`: modId `kacsa_road_upgrade_brush`, revision 2, no dependencies.
- `_metadata/modinfo.json`: name (25 characters), summary (93 characters), description (HTML, English), tags, and author for mod.io.
- `_metadata/0.png`: the cover (1920 x 1080): a screenshot of the game with the title card.
- `_metadata/1.png`: a gallery picture (1920 x 1080): the same screenshot without the card.
- `_metadata/2.png`: a gallery picture (1920 x 1080): the tool at work on a town, with the toolbar, the selected roads, and the build menu.
- `content/gui/road_upgrade_brush/brush_tool@2x.tga` and `brush_tool_preview@2x.tga`: the tool icon and its preview in the menu (green brush over a road). `brush_tool_rail@2x.tga` and `brush_tool_rail_preview@2x.tga` are the same pictures over a railway, for the entry in the rail tools.
