# Only the six base track templates are handled

The Rails mode selects and changes only tracks whose template is one of the six base templates (simple, standard and high speed, each with and without catenary) or a quiet copy of one. A track with any other template is never changed, because a swap would drop what that template adds. A quiet track is swapped to the base template of the target, because the quiet copies belong to the sections of stations with a wall and the tool never builds them.
